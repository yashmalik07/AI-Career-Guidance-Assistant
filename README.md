# 🧭 AI Career Guidance Assistant

An NLP-based Career Guidance Assistant designed to help students explore suitable career paths based on their skills, interests, and career goals.

The project uses Python, Natural Language Processing (NLP), and a career recommendation system to provide personalized career guidance through an interactive chatbot and web interface.

---

## 📌 Project Overview

Choosing the right career can be difficult for students because there are many career options and each career requires different skills.

The **AI Career Guidance Assistant** helps students:

- Explore different career paths
- Identify skills required for different careers
- Get career recommendations based on their profile
- Understand salary ranges and career demand
- Ask career-related questions through a chatbot
- Get guidance about future career opportunities

---

## 🎯 Objectives

The main objectives of this project are:

- Implement basic Natural Language Processing techniques
- Perform text preprocessing and lemmatization
- Identify user intent from career-related queries
- Build a career recommendation system
- Match student skills with career requirements
- Provide personalized career suggestions
- Create an interactive chatbot interface

---

## ✨ Features

### 🤖 AI Career Chatbot

The chatbot understands basic career-related queries and provides relevant responses.

Supported topics include:

- Greetings
- Career paths
- Required skills
- Career recommendations
- Salary information
- Industry trends
- General career guidance

### 🎯 Career Recommendation

The system analyzes:

- Student skills
- Area of interest

and recommends suitable career options.

Each recommendation includes:

- Career name
- Match score
- Matching skills
- Required skills
- Salary range
- Career demand
- Career description

### 🧠 NLP Processing

The chatbot uses NLP techniques such as:

- Text normalization
- Tokenization through word splitting
- Lemmatization
- Pattern-based intent classification

### 📊 Career Information

The system contains career information for roles such as:

- Data Analyst
- Data Scientist
- AI/ML Engineer
- Software Engineer
- Full Stack Developer
- Cyber Security Engineer
- DevOps Engineer
- Product Manager
